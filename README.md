# Targeted Job Search · 精准求职搜索

一个适用于任何行业的求职搜索 skill。它从你的简历提取岗位方向、职级和搜索关键词，在你指定的地区查找职位，并解释每个岗位为什么值得看、还需要核实什么。

## 怎么用

把本目录作为 `targeted-job-search` 安装到支持 Agent Skills 的工具中。Codex 项目级用法：把包含 `SKILL.md` 和 `references/` 的目录放到 `.agents/skills/targeted-job-search/`。如果技能菜单尚未更新，可以直接引用 `SKILL.md`。

在 Codex 中输入：

> $targeted-job-search 帮我找工作。先看我的简历，再确认目标地区。

可以上传简历或粘贴文字；建议先删掉电话、邮箱和住址等联系方式。地区可指定多个城市、一个国家或远程。发「下一批」继续搜索，不重复展示已经推荐过的岗位。

## 搜索和排序

- 从简历提取岗位方向，不预设行业、城市或职业。
- 先搜近 7 天；不够再扩到 10 天，按匹配度每批推荐最多 20 条。
- 区分首次发布、刷新日期和是否仍在招；日期或状态未核实的线索单列，不用来补足 20 条。
- 逐条解释简历证据和关键缺口，并说明来源覆盖与访问限制。

| # | 地点 | 岗位 | 为什么值得看 | 还需确认 |
|---|---|---|---|---|
| 1 | 目标城市 | 公司、职位直链、发布日期、已披露薪资 | 职责对应的简历证据 | 经验缺口、语言、工签或招聘状态 |

## 招聘渠道与权限

根据目标地区搜索招聘平台和雇主官网。支持查看 BOSS 直聘和猎聘的公开职位；如果运行环境支持，也可以读取你已登录后打开的职位页面。遇到登录、验证或访问限制时，会说明实际查到了什么。具体用法见[平台搜索说明](references/china-portals.md)。

Skill 只将岗位和地区关键词用于招聘搜索，不向招聘平台上传简历，也不自动打招呼或投递。所用 AI 工具如何处理简历，取决于该工具的数据设置。请不要把个人简历、搜索档案、投递记录或凭证提交到本仓库。
